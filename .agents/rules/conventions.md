# Development Conventions & Language Guidelines

## UI Language Convention
- **Strict English UI**: All frontend text across Dashboard and Storefront must be in English.
- This includes:
  - Button labels, form labels, and placeholders.
  - Page titles, headings, card descriptions, table headers, and badges.
  - Toast notifications (success, error, warning, info) via `sonner`.
  - Schema validation error messages (Zod, React Hook Form).
  - Empty states, loading states, and confirmation dialogs.
